# Repository instructions

Use the [spec-driven development workflow](specs/README.md) for behavior changes
and new integrations. Start by adding or updating the relevant specification,
then implement it and record how each affected acceptance criterion was checked.
Keep small editorial or formatting changes with the existing documentation.

When documenting the imported demo, derive current behavior from the source
and a running instance when available. Record which checks ran and which are
pending. Capture proposed behavior in a separate section or follow-up spec.
