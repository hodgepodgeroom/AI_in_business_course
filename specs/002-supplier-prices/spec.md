# 002 · Цена из карточки поставщика

Закупщик отправляет список материалов и при наличии добавляет прямые ссылки на товары. Обработчик на компьютере собирает данные для сметы с помощью локальной Qwen3.5. Для сравнения нужны точный товар, размер продаваемой упаковки, валюта, ссылка и время чтения.

| ID | Приёмка |
| --- | --- |
| AC-1 | На странице с одним Product и обычным Offer в RUB обработчик берёт цену из предложения. Модель определяет соответствие товара и упаковки. Цена из поисковой выдачи не вытесняет подходящий товар с ценой на странице. |
| AC-2 | При чтении обычного HTML в контекст модели попадают название и фрагменты вокруг цен, в том числе после длинного меню. Следующая карточка проверяется даже при отказе первых двух. |
| AC-3 | При 403, 429 или странице проверки доступа обработчик переходит к другим источникам. Из этих страниц цена не извлекается. При отсутствии подходящего предложения закупщик видит причину. |
| AC-4 | Пользователь может проверить одну карточку через приложение без внешнего сервиса генерации. В результате сохраняются источник и текстовое основание цены. Доставка с неизвестными условиями остаётся открытым вопросом. |

## Проверка от 18 ноября 2026 года

Испытаны локальный веб-сервер Node.js, SQLite, штатная HTTP-очередь, Python-обработчик и llama-server с Qwen3.5-2B-Q4_K_M.gguf на CPU. Веса взяты из unsloth/Qwen3.5-2B-GGUF. Сначала в заявке была прямая ссылка на карточку поставщика. Затем процесс повторили с одним названием товара, количеством и адресом в Казани. Поиск и скачивание HTML выполнил обработчик.

Обе заявки на шесть мешков цемента AKKERMANN М500 по 50 кг вернули 575 ₽ за мешок, 3 450 ₽ за товар, ссылку на карточку и открытый вопрос о доставке. Источник цены — поле Offer.price в действительной карточке на kamacement.ru. Время и результат относятся к этим прогонам. Сайт поставщика может обновить цены и условия.

Особенность тестовой сети: локальный DNS не разрешал имена поставщиков, а HTTPS через системный прокси работал. Для проверки публичности адреса kamacement.ru испытательный процесс использовал публичную A-запись, полученную по HTTPS. Код приложения продолжает проверять открываемые адреса через системный DNS. Модель, HTTP карточки, поисковая выдача, очередь и сохранение результата в прогоне были настоящими.

Команда `python -m unittest discover -s services/agent` проверяет, в частности, недоступность первых двух источников, чтение третьего, цену в конце длинной страницы, неподходящие валюту и условия, отказ в доступе и соответствие упаковки. Прямые обращения к странице проверки доступа и ответу HTTP 403/429 прекращаются. Для закрытого каталога требуется предоставленный поставщиком источник цены.

В одном из повторов поиск не дал ссылок, и приложение правильно вернуло needs_info. Для этого случая добавлен резервный каталог цемента для Казани. Обработчик читает список товаров у поставщика, сопоставляет их с заявкой и повторно читает актуальную цену на найденной карточке. Другие города и категории по-прежнему используют общий поиск и прямые ссылки.

Резервный маршрут проверен повторной заявкой без URL с искусственно отключённым общим поиском. Поставщик, каталог, карточка и инференс оставались действительными. Обработчик вернул те же шесть мешков и 3 450 ₽. Прошли 16 тестов Python-обработчика, пять тестов веб-приложения и 25 тестов автономного модуля расчёта, а также проверки TypeScript и ESLint.
