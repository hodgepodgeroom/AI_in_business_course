# 003 · Цена из публичного JSON магазина

Закупщик указывает товар и город в обычной заявке. Если карточка загружает цену отдельно, обработчик может прочитать открытый JSON магазина. Локальная Qwen сопоставляет название и фасовку с заявкой. Цену и валюту проверяет код.

| ID | Критерий приёмки |
| --- | --- |
| AC-1 | Для простой карточки WooCommerce с идентификатором товара обработчик читает Store API. Проверяет идентификатор, ссылку товара, тип предложения, наличие и цену в RUB с учётом масштаба. |
| AC-2 | Для настроенного регионального магазина обработчик подставляет артикул карточки и код города, сверяет их с ответом и читает точную цену из указанного поля. При расхождении с явно указанной ценой карточки предложение пропускается. |
| AC-3 | Проверяются источник и формат ответа. При ошибке идентификации, нескольких вариантах, другой валюте или отказе магазина система продолжает поиск. |
| AC-4 | В результате сохраняются карточка, адрес JSON, основание цены и область действия цены. Закупщик может открыть JSON из сметы. Ранее записанные заявки остаются читаемыми. |

## Подключение магазина

Простые товары WooCommerce определяются по идентификатору карточки. Обработчик запрашивает один товар через публичный Store API, использует действующую цену и сверяет её с размеченной ценой в основном блоке товара, если та доступна. Учитываются ограничения количества в Store API и в форме покупки. Если публичный маршрут отсутствует (404, 405 или 410), продолжается обычное чтение карточки. Цена каталога получает пометку «город не подтверждён». [Контракт WooCommerce](https://developer.woocommerce.com/docs/apis/store-api/resources-endpoints/products/)

Для другого публичного JSON API добавьте ключ `supplier_json` в существующий объект `.local/agent.json` и перезапустите обработчик. Ниже пример схемы для условного магазина. Подставьте домен, путь, селекторы, поля и коды городов, соответствующие публичному каталогу вашего поставщика. Настройки подключения обработчика сохраняются.

```json
{
  "supplier_json": {
    "shop.example": {
      "sku_selector": "main[data-sku]",
      "sku_attribute": "data-sku",
      "path": "/api/price/{sku}?city={region}",
      "regions": { "Казань": "16" },
      "fields": {
        "sku": "id",
        "region": "city",
        "name": "title",
        "price": "retail.amount",
        "currency": "retail.currency"
      },
      "visible_price_selector": "main .current-price"
    }
  }
}
```

Путь ведёт к одному товару на том же HTTPS-сайте. Код города и артикул обязательны и должны вернуться в ответе. Селектор артикула должен однозначно указывать на продаваемый вариант. Без `sku_attribute` обработчик берёт текст элемента. Название из JSON должно описывать вариант с фасовкой. Для `price` укажите поле обычной розничной цены одной продаваемой упаковки в рублях. Селектор видимой цены необязателен и должен относиться к выбранному варианту и региону. Для каталога со списком вариантов, оптовыми уровнями, персональными ценами или другой единицей валюты понадобится отдельная логика сопоставления.

Результат сохраняется в существующем JSON заявки. К предложению добавлены ссылка на JSON и регион цены. Для старых заявок эти поля необязательны. Неизвестные доставка и достаточность остатка по-прежнему требуют уточнения.

## Проверка 18 ноября 2026

| Критерий | Вход и наблюдаемый результат |
| --- | --- |
| AC-1 | У «Цемент-Снаб» обработчик открыл карточку HOLCIM М500 Д0, мешок 50 кг, и публичный JSON товара 4643. Поле цены содержало 49000 при масштабе 2, в карточке отображалось 490 ₽. Минимум в форме покупки составлял 20 мешков. Локальная Qwen3.5‑2B подтвердила фасовку. Обработчик рассчитал 9 800 ₽ для 20 мешков и исключил поставщика для шести. |
| AC-2 | Тестовая региональная карточка без видимой цены и ответ JSON содержали один SKU и город. Через обычный метод обработки заявки получена смета на шесть мешков по 575 ₽. Другой регион, артикул, фасовка, валюта и расхождение с видимой ценой проверены отдельными случаями. |
| AC-3 | Проверены диапазон цен, несколько вариантов, HTML вместо JSON и переадресация на другой домен. Отклонённая региональная цена не возвращается в смету через поисковую выдачу по тому же URL. |
| AC-4 | В выбранном предложении проверены обе ссылки и город. Интерфейс проходит проверку типов, ESLint и локальную сборку. |

Команды для повтора автоматических проверок:

```sh
python -m unittest discover -s services/agent
npm --prefix apps/web run typecheck
npm --prefix apps/web run lint
npm --prefix apps/web run local:build
npm --prefix apps/web test
```

В региональных тестах ответы HTTP и модели заданы тестовыми данными. В проверке «Цемент-Снаб» использовались реальные HTTPS-ответы и локальная модель на CPU. Системный DNS испытательной среды не разрешал домен, поэтому только для этого прогона его публичную A-запись получили через DNS по HTTPS. Для воспроизводимости использовался один поставщик, запись хода испытательной заявки в очередь была отключена.
