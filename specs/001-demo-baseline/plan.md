# План реализации и принятые решения

| Этап | Реализация | Связь с приёмкой |
| --- | --- | --- |
| Восстановить исходники | Импортировать каталог React-приложения, Python-обработчик, CLI, исходные данные и независимые проверки обычными файлами Git. | AC-01–07 |
| Обеспечить запуск на одном компьютере | Использовать один React-интерфейс и общий API в локальном и размещаемом режимах. При первом запуске создать SQLite из исходной миграции и сгенерировать ключ обработчика. | AC-01, AC-06, AC-07 |
| Сохранить очередь при сбое | Условные переходы статусов, аренда с идентификатором и продлением, повтор с очисткой старого результата. | AC-02, AC-03 |
| Подключить модель | Передавать путь к GGUF при запуске либо использовать уже запущенный сервер chat/completions. Для извлечения установить схему JSON. | AC-04 |
| Отделить расчёт от генерации текста | Считать суммы и упаковки с Decimal. Хранить происхождение цены. Для расчёта по нормативам сохранить независимый офлайн-CLI. | AC-03, AC-05 |
| Проверить переносимость | Собрать интерфейс, проверить доступ владельца и аренду на временной базе, повторить учебный расчёт и варианты с неполными данными. | AC-01–07 |

Локальный режим рассчитан на одного пользователя. Разделение прав нескольких участников, OCR и отправка заказов поставщикам требуют отдельных спецификаций.
